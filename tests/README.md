# Tests

Two kinds of tests, both run from the shell and needing only Python 3 (standard library).

## Quick checks against known answers — `run_checks.py`

```bash
make test                                   # = python3 tests/run_checks.py ./mclics   (CPU modes)
make test-gpu                               # the same checks with the GPU modes (thermalGPU, ...)
python3 tests/run_checks.py path/to/mclics -k ground   # only the checks whose name contains "ground"
```

About 20 small runs (a few seconds in total) whose result is known exactly or within a small tolerance:

| Group | What is checked |
|---|---|
| Ground states at T = 0 | uniform state of LL (E = −9 per site, S = 1), GHRL with equal K's (E = −6), pear (E = 6(−A − B1), P = 1), slab with homeotropic anchoring, dielectric field (also checks that the field direction is normalized) |
| Observables | outward hedgehog in a pear droplet: `Sr_sph`, `Pr_sph` ≈ 1 and `divn` ≈ 0.275; `po.dat` columns for LL in a sphere |
| Sweeps and files | temperature points (the last one is exactly `Tf`), snapshot names for normal and fine steps, electric sweep (`field` column, last point included), block numbers in step mode, ordering after a quench, a snapshot read back as `ic_file` |
| Reproducibility | the same seed gives the same `po.dat`, another seed a different one |
| Input errors | odd periodic size, `dT` with the wrong sign, unknown parameter, unknown anchoring type, negative temperature: the run must stop with a message and leave the previous `po.dat` untouched |

The exit status is 0 when every check passes. Failed checks keep their run folders (printed at the end) with the
input and `run.log`.

## Regression test — `regression/run_regression.sh`

Compares two versions of the program on 7 cases that cover the four evolution modes, the four geometries, the LL,
GHRL and pear potentials, the LL-form and GHRL-form anchorings, `ic_file` and the electric field:

```bash
cd tests/regression
./run_regression.sh OLD_PROGRAM NEW_PROGRAM          # GPU modes
./run_regression.sh --cpu OLD_PROGRAM NEW_PROGRAM    # CPU modes, one thread (a few minutes)
```

Use it after a change that should not affect the results (refactoring, comments, performance), with
`OLD_PROGRAM` = the program built before the change: every case must be `IDENTICAL`. The runs are kept in
`regression/out/` and the comparison in `regression/out/summary.txt`. The geometry and initial condition of the
cylinder case are generated by `make_cylinder.py`.

On the CPU, use `--cpu` (one OpenMP thread): with several threads the trajectory depends on how the sites are
shared between threads, so two versions would differ even when the code is equivalent.
